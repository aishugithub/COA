Based on the syllabus for CSE23CT201: Computer Organization and Architecture and the referenced textbooks (Hamacher and Morris Mano), here are the detailed teacher's notes for Units 1 and 2. These notes are organized to build concepts from basic hardware components to the complex logical execution of programs.
Unit 1: Basic Structure of Computers
Chapter 1: Foundations and Functional Units
Computer Architecture vs. Organization:
Architecture refers to the attributes of a system as seen by the programmer (instruction sets, bit representations, addressing modes)
.
Organization refers to the operational units and their interconnections (hardware details, control signals)
.
The Five Functional Units (Hamacher):
Input Unit: Accepts coded information (binary) from human operators or other computers
.
Memory Unit: Divided into Primary Storage (fast RAM for active programs) and Secondary Storage (permanent, larger capacity like disks/flash)
. Cache memory is a high-speed adjunct to main memory to facilitate faster execution
.
ALU (Arithmetic and Logic Unit): Where actual data processing (add, subtract, logic) occurs using operands in registers
.
Output Unit: Sends results to the outside world (printers, displays)
.
Control Unit: The "nerve center" that coordinates all other units via timing signals
.
Chapter 2: Basic Operational Concepts
Stored Program Concept: Programs (instructions) and data are stored in the same memory; the processor fetches instructions one by one
.
Key Registers:
Instruction Register (IR): Holds the instruction currently being executed
.
Program Counter (PC): Points to the memory address of the next instruction to be fetched
.
MAR & MDR: The Memory Address Register holds the address for a transfer, and the Memory Data Register holds the actual data being read or written
.
Instruction Cycle Basics: The simplest execution involves two phases: Fetch (getting the instruction from memory) and Execute (performing the task)
.
Chapter 3: Bus Structures and Memory Addressing
Common Bus System: A set of wires that allows data transfer between multiple registers and memory
. Implementation often uses multiplexers to select the source register
 or tri-state buffers to allow multiple devices to share the path
.
Memory Addressing:
Byte-Addressability: Each 8-bit byte in memory has a unique address
.
Endianness: Big-Endian assigns lower addresses to more significant bytes; Little-Endian does the opposite
.
Word Alignment: Words are "aligned" if they start at addresses that are multiples of the word length in bytes
.
Chapter 4: Instructions and Sequencing
Notation:
Register Transfer Notation (RTN): Symbolic description like R2←[LOC] (load contents of memory location LOC into register R2)
.
Assembly Language: Uses mnemonics (LD, ST, ADD) to represent machine code
.
Sequencing:
Straight-Line Sequencing: The processor increments the PC to fetch instructions in order
.
Branching: Loads a new address into the PC to change the execution flow (essential for loops and decisions)
.
Design Styles: RISC (Reduced Instruction Set) uses simple, one-word instructions and a load/store architecture
. CISC (Complex Instruction Set) allows multi-word instructions and operations directly on memory operands
.
Unit 2: Processing Units
Chapter 1: Register Transfers and Microoperations
Register Transfer Language (RTL): A symbolic language used to describe the internal movement of bits between registers and memory
.
Control Functions: Transfers often occur only if a specific condition is met, written as P:R2←R1 (if P=1, transfer R1 to R2)
.
Memory Transfers:
Read: DR←M[AR] (transfer memory word at address AR to data register DR)
.
Write: M[AR]←R1 (transfer register R1 to memory word at address AR)
.
Chapter 2: Arithmetic and Logic Operations
Arithmetic Microoperations: Addition, subtraction, increment (R1←R1+1), and decrement (R1←R1−1)
.
Logic Microoperations: Bit-wise operations like AND, OR, NOT, and XOR
. These are used for tasks like masking (ANDing to clear bits) or selective-set (ORing to set bits)
.
Shift Microoperations:
Logical Shift: Inserts a 0 into the vacated position
.
Arithmetic Shift: Preserves the sign bit during a right shift (used for signed division by 2)
.
Rotate (Circular) Shift: Bits shifted out of one end are inserted into the other
.
Chapter 3: Execution of Complete Instructions
The Processor Datapath: Consists of the ALU, the register file, and interstage registers (RA, RB, RZ, RM, RY) that hold data as it moves through the processor
.
Five-Step Execution Sequence (RISC style):
Fetch: Instruction is read from memory; PC is incremented
.
Decode: Determine the operation and read source registers
.
Compute: The ALU performs the operation or calculates an address
.
Memory Access: Read or write data if it's a Load/Store instruction
.
Write Back: The result is stored in the destination register
.
Chapter 4: Organization and Control
Multiple Bus Organization: Using three buses (Bus A, B, and C) to allow simultaneous movement of two operands to the ALU and the result back to the register file
.
Hardwired Control: A combinational circuit generates control signals based on the IR and a step counter
.
Microprogrammed Control: Control signals for each execution step are stored as microinstructions (control words) in a special control store memory
.
A Microprogram Counter (μPC) tracks the address of the next microinstruction to be read
.
This allows the processor to execute machine instructions by running small microroutines
.
Teacher’s Note for Delivery: When teaching Unit 2, emphasize the transition from Unit 1’s functional blocks to the actual logic gates (ALU) and timing (Instruction Cycle) that make them work. Use the five-step sequence as the "rhythm" of the processor to help students visualize how a single line of assembly code turns into several physical hardware actions.
